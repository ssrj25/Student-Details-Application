# Student Details Application

A full-stack student management application for creating, viewing, updating, and deleting student records.

## Tech Stack

- React.js
- Material UI
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios

## Features

- Student record management
- REST API integration
- MongoDB persistence
- Responsive React interface
