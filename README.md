# Student Details Application

A full-stack student management application built with React and Node.js. It provides a web interface for managing student records through a REST API backed by MongoDB.

## What It Does

Users can view all students, add new student records, open individual records, update existing details, and delete records. The React frontend communicates with an Express.js backend, which exposes REST endpoints and stores the data in MongoDB using Mongoose.

## Key Features

- Add student records
- View all students
- View individual student details
- Update student information
- Delete student records
- REST API integration
- MongoDB data persistence
- Responsive React interface

## Tech Stack

- React.js
- Material UI
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios

## API Operations

- `GET /all` — Retrieve all students
- `POST /add` — Add a student
- `GET /:id` — Retrieve a student
- `PUT /:id` — Update a student
- `DELETE /:id` — Delete a student
